# Apresentacao Comercial - Vai de Bet

Este repositorio contem o material editavel da proposta comercial da Spin para o projeto de mesas dedicadas da Vai de Bet.

## Arquivos principais

- `Apresentacao_Comercial_Spin_VaideBet.pptx`: apresentacao final editavel.
- `generate_vaidebet_presentation.py`: script para regenerar o deck e os mocks visuais.
- `assets/generated/`: imagens auxiliares geradas (casting, perfil, roteiro e variacoes de logo).

## Como regenerar o PPT

```bash
python3 generate_vaidebet_presentation.py
```

O comando recria o `.pptx` e atualiza os arquivos da pasta `assets/generated/`.
